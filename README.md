# dev-ai-kit

仓库地址：https://github.com/hanxuzz/dev-ai-kit

同事用 Cursor 打开业务项目，把本仓库地址发到对话里即可。用法见 [开始.md](开始.md)。Cursor 会把套件克隆到业务文件夹外面。不要把套件放进业务项目里，也不要在说明里写某一台电脑的路径。

# 变更范围

先说明变化来自哪里、原来确认了什么、现在新增/删除什么，以及受影响的 R、任务、接口、数据和测试。
`change --by ... --note ... --expect ...` 保留历史并使旧确认和任务完成状态失效。用 prepare 更新材料及映射，保留明确不做。
复核影响和依赖，再经用户真实确认运行 confirm。当前版本保守地重新打开本需求所有任务，核对已实现的无需重复改代码，但重新验证。
变更确认不是提交、发布或操作外部系统的授权；连续执行中出现新范围也应停在这里。

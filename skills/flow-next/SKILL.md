# 下一步建议

用户说「现在该做什么」「还差什么」「接下来呢」「怎么继续」，或含糊地停住时，先做这件事，不要改代码。

每个其他技能正常做完后，也要做一次。

## 怎么做

1. 工作区是 Cursor 打开的业务项目根目录，不是套件仓库。
2. 运行套件里的 `scripts/next.ps1 -Workspace <工作区>`（macOS 用 `scripts/next.sh`）。
3. 以工作区 `.cursor/next-step.txt` 为准（UTF-8）。控制台若是乱码，不要猜，读这个文件。
4. 「下一步由你来做」：本轮执行，做完把结果告诉用户。需要拍板时只问那一个问题。不要把这行原文交给用户复述，也不要预告更后面的步骤。
5. 「下一步请用户定」：用自己的话问这个问题，然后停下。不要改代码来填这个空。
6. 「下一步就做这一句」只用于旧输出。新脚本不再靠用户把这句话发回来。
7. 「还可以稍后做」和「还可以优化」放在后面，不要抢在当前这一步前面。
8. 脚本指出被挡住或问题未确认时，不要改去写开发顺序或业务代码。

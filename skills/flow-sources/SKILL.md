# 来源与版本

使用本次用户给出的或项目明确指向的材料，不全盘扫描共享目录。
已有 Spec、文字工单、用户明确陈述都可以作为来源。登记来源编号、类型、版本或读取时间、链接/相对快照、collected/pending/skipped 和原因。
需要视觉还原时查看对应原件；普通文字修改可以使用已确认文字和现有页面。链接无权限时记录 pending，不把链接本身当作已读正文。

二进制优先留原处或已授权共享目录；不因没配置共享盘就丢弃本地可读材料。需要复制时明确目标和授权范围，避免把敏感原件加入代码提交。
通过 prepare 保存摘录和 sources；材料间或与代码事实矛盾时登记问题、questions=open。已经生成的原有文档保留，但不能把未决变化写成最终方案。
可变远程来源在开始实现和最终验收前重新确认版本；脚本只能检测本地快照及登记信息的变化。

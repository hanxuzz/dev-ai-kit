# 适用范围与流程分级

适合已有代码、可明确验收的业务改动：单仓、多仓父目录、既有规格接管、跨对话接续。
不适合以完整交付门禁管理尚无目标的研究探索；这类任务先保留研究记录，等范围清楚再接入。

| profile | 场景 | 材料 |
|---------|------|------|
| quick | 小修复、文案、明确字段行为 | 一份 brief：范围、不做、影响、任务；最小 R/TASK/T 映射 |
| standard | 常规业务需求 | 沿用或编写规格、影响点、计划，配套验收映射 |
| cross-system | 跨仓接口、数据迁移、权限或多服务交付 | standard 加接口、数据、权限、异常、异步缓存、交付顺序、回退评估 |

profile 决定材料深度，不降低权限、范围确认和验证要求。允许纯文字、仅工单或已有 Spec；录像和 Figma 都是按需求选用的来源。
缺数据库不挡单元测试，缺浏览器不挡后端验证，缺录像不挡文字需求。

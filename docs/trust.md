# 依据、确认与权限

1. 业务仓 AGENTS.md、现有规则和已确认团队规范约束代码、分支与提交。收集时保留来源，不修改原文。
2. 已确认规格确定范围内、明确不做和验收。计划不能新增范围，原始设计不能默默扩大已确认范围。
3. 代码和接口是现状依据；原始工单、设计、截图是需求来源。二者与规格冲突时先澄清。
4. 结构化映射和脚本决定状态门禁；文件存在、模板已复制、口头「应该可以」不表示完成。

确认记录绑定材料、任务、用例和来源版本摘要。变更后复核范围并重新确认，不能只把一个布尔值改回 true。
用户可以一次授权一批明确任务；材料整理、业务执行、提交、推送、部署的授权分别判断，不能互相推导。

## 操作模式

| 用户意图 | Agent 行为 |
|----------|------------|
| 看看进度、下一步是什么 | 只读 next/status，解释当前状态 |
| 整理材料、接管旧需求 | 准备来源、映射、范围和待确认问题；不改业务代码 |
| 做一步、做某个任务 | 检查门禁后执行该任务、验证、报告，停止 |
| 按已确认计划连续执行 | 在本次明确授权范围内逐个做满足依赖的任务；遇到新范围、阻塞或需要确认时停 |

每个技能结束可读取 next，但读取结果不是下一次执行的授权。规则不要求用户复述脚本输出。

轻量路径也要有范围和验收；涉及视觉还原时必须查看设计原件，普通文案或字段修复可使用已确认文字和现有页面。缺少不相关工具不阻挡当前任务。

不与已确认需求冲突的首次明确小改动请求可以同时构成范围确认和执行授权，不要求额外重复确认；Agent 必须记录真实原话及确认者，脚本不提供身份认证。仅询问、建议或整理材料不能转换成执行授权。结构化变更只确认新增决定；已确认且未受影响的内容保留。

## 明确要求即可提交或推送

“未经要求不推送”限制的是擅自操作，不是禁止 Agent 代用户 push。用户明确说“push”“推送”“提交并推送”，就是对应操作的执行授权；目标和范围清楚时核对 Git 状态、必要检查及远端后直接执行，不再问一次“是否允许我代为推送”。同一事项已有授权可继续使用，用户撤回或缩小范围时遵循最新要求。

| 用户要求 | 执行边界 |
|----------|----------|
| 修复、测试、继续开发 | 不因此 commit 或 push |
| 提交 / commit | 提交本次相关改动，不自动 push |
| push / 推送已有提交 | 推送指定仓库/分支的预期提交，不自行提交其他未提交修改 |
| 把这次修改提交推送 / 提上去 / 提交上去 | 上下文明确指本次修改送到远端时，完成必要 commit 后 push，不拆成重复授权问题 |

`push.only_when_asked: true` 表示明确要求后允许推送，不是禁用推送。推送授权不包含 force push、绕过保护/钩子、修改 Git 配置或额外部署。存在目标歧义、非预期待推送提交或真正的项目限制冲突时，说明具体问题；不得仅以“套件不能代 push”为由拒绝。核心 CLI 不自动执行 Git 写操作，实际由 Agent 的 Git 工具执行，不代表 Agent 没有代操作能力。

## 已确认需求变化必须二次确认

每次开发、续做或修复前，将最新请求与已确认规格、验收、不做事项及已有决定比较。新增、删除或改变已确认业务行为、范围或验收均属于变更，即使用户语气明确、修改很小或已有连续执行授权，也不能把首次变更请求当成二次确认。首次需求且无冲突、语义不变的整理、恢复已确认行为的 Bug 修复不增加此门槛；名为修 Bug 但改变预期行为仍是需求变更。

先只读调查并使用 assist change 预览，不覆盖已确认材料、不 apply/confirm、不改受影响业务代码或测试预期。可以准备独立草稿和继续不受影响的已授权工作。若怀疑用户记错，引用实际来源和位置，平实说明差异，不直接断言用户记错；找不到依据时说明不确定，不能编造旧需求。

向用户展示：原要求及来源 → 新请求 → 行为/验收和影响范围 → 保持不变部分，然后明确询问采用哪一个。例如：“原规格 R2 要求订单保留 30 天，你现在要求 7 天，会改变历史订单查询范围。是确认改为 7 天，还是仍保留 30 天？”

必须等用户针对已展示差异再次明确确认，才应用变更、记录确认和开始修改。沉默、超时、泛泛‘继续’、首次改动请求或旧的‘全部按你理解做’不能代替这次确认；‘确认按上面的 7 天方案修改’可以。同一批已展示变更可一次确认，无须逐字段重复问。记录原请求、旧来源、展示差异与用户实际回复，confirm 的 note 引用真实二次确认依据，不代填用户答复。

等待期间新请求再变或出现实质新增影响，更新差异后再次确认；已确认且未变化的部分不重复问。发现已误改时暂停，不擅自回滚他人修改，说明实际差异并取得处理决定。工具指纹能检查材料版本，不能证明自然语言确认真实发生；此判断由 Agent 依会话证据执行。

# 凭证与运行边界

密码、令牌和连接串保存在团队允许的凭证管理器；本套件约定使用已配置的 Bitwarden 能力，仓库只记录文件夹和条目名。
不复制个人 mcp.json，不保存会话令牌，不在聊天里索要主密码。

接入方法以当前已安装客户端/连接器的官方说明和实际工具 schema 为准；套件不假设所有环境都有相同的 MCP 包名或 unlock 命令。
无法调用时只报告缺少能力，由用户完成登录/解锁，或按本次明确授权的官方流程处理。

数据库条目写在 runtime.database.bitwarden，readonly 表示只允许使用真正只读账号。布尔配置不能证明实际权限。
用户未授权连接时不代连；没有数据库依赖的测试不需要读取数据库凭证。

命令参数、环境文件、验证说明和日志中均不保存口令。自动验证默认只持久化输出摘要；人工 note 也应脱敏。
套件不是沙箱：必须核对已有命令是否会改数据、发送请求或部署；有外部副作用的命令不能仅凭名称包含 test 就运行。

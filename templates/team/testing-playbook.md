# 项目测试执行经验

优先链接项目已有测试代码，不复制整套脚本。按已验证用例逐条记录；下面是待填写字段，不是已核实事实。

## 用例 / 需求标识

- 状态：待核实 / 已验证 / 已失效（只能选择实际状态）
- 入口：项目相对脚本路径、既有 check 名或明确交互步骤
- 环境与角色：实际核实目标、版本和测试角色；不写凭证
- 前置与清理：服务就绪、数据隔离、登录状态及清理责任
- 操作与断言：语义定位/页面对象引用、关键动作、可观察预期
- 适用依据：相关源码、用例、测试配置、锁文件等相对路径及内容摘要；工具版本
- 成功证据：真实运行时间、结果和可回查的证据引用；不得用生成时间代替执行时间
- 失效条件：需求/实现/配置/角色/工具变化；动态事实每轮核实
- 最近复用：本轮核对了什么、复用什么、重跑什么及原因
- 排障经验：失败症状、已验证原因与恢复方法；不把失败记成通过
